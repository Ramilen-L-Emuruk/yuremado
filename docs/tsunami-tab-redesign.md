# 津波タブの見直し

津波タブ（津波の警報・注意報のバナーと、等級ごとのカード・区域・観測点の一覧）の見せ方を、作り直した地震タブ（[`quake-tab-redesign.md`](quake-tab-redesign.md)）にそろえるための資料。
読み手は、この見直しに関わる開発者。

## 共通の物差し（共通部のセッションから配られたもの）

アプリ全体を地震タブに揃える決定（上の表の 1 行目）に沿って、全画面で共通にする値（弱い字の色・面と線の色・角丸の 3 段・影・開閉の動き・器の幅 520px で切り替える文字の 2 組）を、共通部の作業（ブランチ `worktree/feat/ui-common`）が決めて各タブへ配った。津波タブもこれに合わせる。等級ごとの色はその中で変えないものとされている。

## 確かめたこと

### 大津波警報テストの後に区域の等級変化テストを押すと、原因地震が 2 つ並ぶ件

2026-11-04 に地震タブの作り直しの版（dc7594ac）で押し直したところ、原因地震は能登の 1 つだけで、並ばなかった。
別の地震の津波で置き換えたときに前の原因地震を残すのは決めた仕様（`JMATsunami.previousSourceEarthquakes`。2026-10-21「置き換え、前の地震も残す (Recommended)」・2026-10-24「同じ形で後に並べる (Recommended)」）。

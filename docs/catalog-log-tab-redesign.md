震源カタログのタブ（絞り込み・見せ方・件数）と電文ログのタブ（一覧と中身）の見せ方を、地震タブ（[`quake-tab-redesign.md`](quake-tab-redesign.md)）に合わせて作り直すための資料。
読み手は、この作り直しに関わる開発者。

### 電文ログ

**数えた範囲**: メインの checkout の `.cache/dmdata-archive-cache/` の日ごとの束 3,768 本。分類はライブの購読の区分（`eew.forecast`・`eew.warning`・`telegram.earthquake`）と同じ 3 つで、中継が名乗る区分も覆う。束のある日は分類で違う。

| 分類 | 束のある日 | 期間 | 欠けた日 |
|---|---|---|---|
| `telegram-earthquake` | 2,147 日 | 2020-11-18〜2026-10-31 | 27 日（配信が無かった日か、取っていない日かは未確認） |
| `eew-forecast` | 1,552 日 | 2022-07-20〜2026-10-18 | なし |
| `eew-warning` | 69 日 | 2022-08-11〜2026-10-16 | 1,459 日（警報の無い日が大半とみられるが未確認） |

束の中のファイル名から種類と形式を、目録（`telegrams.json`）の `head.test` から試験報の数を数えた（通信はしない）。束には同じ電文の DMDATA の JSON 形式も入るが、アプリは XML の素の形（`formatMode: 'raw'`）だけを受ける。

**中身の表示は電文をそのまま出す。** XML の電文は本文を丸ごと出すので、要素と属性はすべて画面に出る（`TelegramTab/index.tsx` の `formatEntryForView`）。取りこぼすのは、行が積まれない経路と、本文が置き換わる経路と、DMDATA の `head` が付かない経路だけ。

#### 経路ごと

| 経路 | 行を積むもの | 積まないもの | `head` | 行を持つ数 |
|---|---|---|---|---|
| ライブ（中継・自分の鍵） | 読んだ電文、読めなかった電文（`error`）、捨てた試験報（`filtered`）、取り込まない緊急地震速報（VXSE44・予報を受けている人の VXSE43） | **本文を復号しない種類（VXSE56 の実配信）**、試験報を受ける設定のときの VXSE42 | 出る | 直近 24 時間 |
| 再生（リプレイ） | 読んだ電文 | **試験報・扱わない種類（VXSE42・VXSE56）・控えのある日の VXSE44・予報を受けている人の VXSE43・読めなかった電文**（`dmdataReplay.ts` の絞り込み。読めなかった電文は 2026-10-23 ユーザー選択「今回は載せない（推奨）」） | **出ない**（`telegramLogEntry.ts` の `makeReplayLogEntry` が持たない） | 100 行（開始・停止で空にする） |

### 震源カタログ

取得元は気象庁「地震月報（カタログ編）」の震源レコード（1 行 96 文字。[フォーマット](https://www.data.jma.go.jp/eqev/data/bulletin/data/format/hypfmt_j.html)）と、確定前の期間の日別の震源リスト（速報値）。生成スクリプト（`scripts/build-hypocenter-catalog.ts`・`scripts/hypocenterRecord.ts`・`scripts/hypocenterDailyRecord.ts`）が残すものと、画面（地図の点の吹き出し・絞り込み）が出すものを突き合わせた。

#### 行（どの地震を収録するか）

| 絞り込み | 根拠 |
|---|---|
| M2.0 未満は収録しない（M が決まっていない地震は残す）。1997 年以降の J の 4,987,693 件のうち 4,048,253 件（81%）が M2.0 未満 | 2026-08-25 ユーザー発言「M2.0 以上」「それで着手しましょう」。M 不明を残すのは 2026-10-14 ユーザー選択「全期間で収録する」（`data-sources-spec.md` §6） |
| レコード種別が J・U・I 以外の行は捨てる | フォーマットの種別はこの 3 つだけ（想定 0 件） |

# リアルタイムタブの見直し

リアルタイムタブ（緊急地震速報のカード・主要動の到達カウントダウン・強震モニタの揺れ検知のカード・下の説明）を、地震タブの作り直し（[`quake-tab-redesign.md`](quake-tab-redesign.md)）と同じ見た目へそろえるための資料。
読み手は、このタブに関わる開発者。
「狭い組」「広い組」は地震タブと同じ 2 組で、タブの器の幅が 520px 未満か以上かで切り替わる（[`spec/architecture-spec.md`](spec/architecture-spec.md) §4）。

## 決まっていること

| 決定 | 原文 |
|---|---|
| 緊急地震速報のカードを、地震タブの開いたカードと同じ骨組みにする（左に震度の枠、右に震源と値）。並べ方の細部は [`spec/eew-spec.md`](spec/eew-spec.md) §3 | 2026-11-04 選択「この形で決める (Recommended)」。途中の発言「少なくとも欲しいのは縦画面でも主要な情報がスクロールしなくても見れるようにすることです。」 |
| 時刻は 2 つを並べ、大きく出すのは地震発生時刻だけ。地震発現時刻はその真下に小さく弱い字で 1 行 | 2026-11-04 発言「発生時刻と発現時刻を同じ大きさで並べる必要はないと思います。」「時刻大事な方はもっと大きく表示してもいいんじゃない？」「時刻が別の場所にあるのも気になるし、重要じゃないほうが薄くなくて白文字なのも気になります。」 |
| M・深さは時刻の下に横に並べる（時刻の右へ縦に積む形はやめる） | 2026-11-04 発言「さっきのほうがマシですね。戻しましょう。」 |
| 震度の枠の幅は地震タブの枠より広げる（狭い組 90px・広い組 154px。地震タブは 72px・128px）。「予想最大震度」は枠の幅に 1 行で入る大きさにする。数字・長周期の帯の字も枠に合わせて大きくする | 2026-11-04 発言「予想と最大震度が分かれてるのがなんか気持ち悪いです。」「どうせ右もっと空いてるんだからもっと幅広げたら？」、続く選択「この形で決める (Recommended)」（説明「上に「予想最大震度」を 1 行、数字と下端の「長周期2」も枠に合わせて大きく」） |
| 狭い組（スマホ）では、震源名・時刻・M・深さの大きい字を地震タブの狭い組の 0.82 倍に詰め、値の段・付加文の枠の上下の隙間を詰める。「警報:」「予報:」の県名は見出しと同じ行に続ける | 2026-11-04 発言「スマホ画面は遠くから見ることがないため、もっと情報を詰めることも検討していいと思います。」「スマホ画面はもう少し詰めてみて。」「余白多すぎない？」 |
| 震度の枠の下端の長周期の帯は「長周期2」と書く（地震タブの枠の帯と同じ書き方。程度以上は「長周期2程度以上」）。予想であることは枠の上の「予想最大震度」が受け持つ | 2026-11-04 選択「「長周期2」 (Recommended)」 |
| 地震発生時刻・地震発現時刻は「11月4日 1:13:27」と書く（地震タブの「11月4日 0:49」に電文が持つ秒を残した形） | 2026-11-04 選択「「11月4日 1:13:27」 (Recommended)」 |
| 主要動の到達（予測）の一覧は、狭い組でも 2 列にする（27 区域の報で 27 行が 14 行になる。長い区域名は「…」で切れることがある）。自動で送る（流す）形にはしない。広い組は 2〜3 列のまま。並びは変えない（[`spec/eew-spec.md`](spec/eew-spec.md) §4「並びは時間の順」） | 2026-11-04 選択「2 列、送らない (Recommended)」（同じ日の先の選択「狭い組では 1 列にする (Recommended)」を覆した）。途中の発言「二列にして自動スクロールするようにするのはどう？」 |
| ただしタブの器が 360px 未満のときは到達一覧を 1 列に戻す（幅 320px の 2 列では 27 区域のうち 22 件の名前が 2〜3 文字まで切れた） | 2026-11-04 選択「とても狭いときだけ 1 列 (Recommended)」 |
| 到達一覧の震度の札は、地震タブの震度の枠と同じ組み立て（震度の色の縁・白い字）で、地は震度の色を 35% 混ぜた明るさにする。札の幅は一覧でいちばん広い札にそろえる。揺れ検知のカードの震度の棒の札も同じ色にする | 2026-11-04 発言「ちょっと見にくいけど、でも統一感は持たせたいですね。」「範囲があるもののせいで揃ってないのが気になります」、続く発言「うーん、Dがやっぱいちばんなのかなぁ」。D 案は、見本として示した 4 案（A 今の塗りつぶし・B 地震タブと同じ濃い地で縁 1px・C 縁 2px で地を明るく・D C の札の幅をそろえる）の 4 つ目で、続く選択「2 列、送らない (Recommended)」の問いはこの形の札を前提に組んだ |
| 主要動の到達カウントダウン（ホーム地点の区域の秒数）のカードを、緊急地震速報のカードより上へ移す。2 行に詰め、見出しは「主要動」だけにする（届いたかどうかは値の行が伝える） | 2026-11-04 発言「もちろん上に持ってきはしたいんだけど、そうするとEEWの大事な情報が見えなくなったりしない？」、続く選択「詰めて上へ (Recommended)」 |
| 緊急地震速報の取消の覆いは、見ている間に取消が届いたときだけ 250ms で薄くから出す（地震タブの取消の覆いと同じ動き。最初から取消済みで描いたカードは動かさない） | 2026-11-04 選択「出す (Recommended)」 |
| 揺れ検知のカードの最大リアルタイム震度も、緊急地震速報と同じ震度の枠（濃い地・震度の色の縁・震度の色の見出し・白い数字）にする。カードの地は他のカードと同じ色にし、外の縁は最大震度の色。枠の幅は緊急地震速報の枠を下限に、見出しが 1 行に入る幅まで広がる | 2026-11-04 選択「そろえる (Recommended)」 |
| 見出し「最大リアルタイム震度」は折り返さない（上の行の枠の幅の決め方はこれに合わせた） | 2026-10-31 ユーザー承認「折り返したりが起きないなら最大リアルタイム震度がいいですね」（`RealtimeTab/index.tsx` の注記） |
| パネルの中の弱い字は `text-secondary`、角丸は 3 段（札 3px・枠 4px・震度の枠とボタン 6px）、字は地震タブの 2 組（器の幅 520px で切り替える）にそろえる | 全画面の見直し（地図の上・帯・小さい窓などタブをまたぐ部分）で諮った問いへのユーザー選択「全部揃える (Recommended)」「帯と窓だけ揃える (Recommended)」。問いと選択肢の説明の原文はこの資料には無く、その見直しのブランチ（`worktree/feat/ui-common`）の資料に置かれる |

**電文の値は変えていない。** 文言で変えたのは、時刻の書き方、長周期の表示（「予想長周期地震動 階級2」の帯を、震度の枠の下端の「長周期2」へ）、カウントダウンのカードの見出し（「主要動 到達カウントダウン」「主要動 到達済み」を「主要動」へ）の 3 つ（上の表）だけ。

## 実装の置き場所

- カード: `src/components/RealtimeTab/index.tsx`（`EEWCard`・`SWaveArrivalCard`・`KyoshinDetectionSummary`）
- 寸法: 地震タブの `--qk-*`（`src/index.css` の `quake-list`）に、このタブだけの係数を掛ける。タブの器（`quake-list-scope`）に置く
  - `--rt-k`: 大きい字の係数。狭い組 0.82・広い組 1
  - `--rt-tw`: 震度の枠の広げ方。狭い組 1.25・広い組 1.2
  - `--rt-tile-w`: 震度の枠の幅（`--qk-big` × `--rt-tw`。`--qk-big` は狭い組 4.5rem・広い組 8rem なので 90px・154px）
- 震度の枠の色: 地震タブの `quakeTileColors`・`TileScaleLabel`（`src/components/EarthquakeTab/QuakeListRow.tsx`）
- 取消の覆いの動き: `fadeIn`・`CANCEL_FADE_MS`（`src/components/EarthquakeTab/quakeMotion.tsx`）
- 到達一覧の札の幅: 描いた後に一覧の札をすべて測り、いちばん広い幅を一覧の器の `--rt-badge-w` に置く（`arrivalListRef`）

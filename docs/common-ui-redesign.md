# 共通部の見直し

どのタブにも出る部分（地図の上に乗るもの・ナビ・地図とパネルの境・帯・行動チェックリスト・小さい窓）の見せ方を、
作り直した地震タブ（[`quake-tab-redesign.md`](quake-tab-redesign.md)）に揃えるための資料。
読み手は、共通部（地図の上の面・ナビ・境・帯・行動チェックリスト・小さい窓）を触る開発者。タブごとの見直しの資料は
[`tsunami-tab-redesign.md`](tsunami-tab-redesign.md)（津波）・[`settings-window-redesign.md`](settings-window-redesign.md)（設定の窓）にある。

## 各タブの見直しから届いた、横展開するもの

タブごとの見直しで決まり、全画面へ配ったもの。決めた原文はそれぞれのタブの資料にある。

| 届いた先 | 中身 |
|---|---|
| 津波タブ（`docs/tsunami-tab-redesign.md`） | 枠つきの箱を並べた一覧は、細い線で区切った表の行にする。巻いたときに上に残すものは地震タブの規則（貼りつく高さが見える高さの 4 割までなら大きな枠、超えたら 1 行の帯）にし、中の段の見出しはその段を巻いている間は帯の下に貼りつける |
| 設定の窓（`docs/settings-window-redesign.md`） | 操作のボタンは枠のボタン（地 `bg-panel`・線 `border-border`・角丸 6px・乗せたら明るく）。選んだ震度の横の小さな札は地震一覧の小さな枠と同じ作り。「 / 」で繋いだ出典・リンクの行は 1 つ 1 行にし、器の幅 520px 未満はラベルの下に左寄せ、以上はラベルの右に右寄せ。オン・オフのつまみは丸いまま（角丸 3 段の例外） |

## 部品

| 部品 | 置き場所 | 使い方 |
|---|---|---|
| 収まらない文を流す | `src/components/Marquee.tsx`（動きは `src/index.css` の `.marquee-run`） | `<Marquee text={文} className="…" />`。外枠は `block min-w-0 overflow-hidden whitespace-nowrap`。flex の中では `flex-1` などで幅を決める。`mode="return"` にすると、末尾まで流して 1.5 秒止まり、頭へ戻って 1.5 秒止まってまた流す（電文ログの開いた行の名前） |
| 帯・窓の文字の 2 組 | `src/index.css` の `ui-text`（幅の問い合わせを置く器）と `ui-text-scope`（値を持つ中身） | 中で `text-(length:--ui-f)`（本文）・`text-(length:--ui-fs)`（小）を使う。中身の幅に合わせる箱（`w-fit`）を器にしない（幅が 0 に潰れる） |
| 開閉の動きと印 | `src/components/EarthquakeTab/quakeMotion.tsx` の `Reveal`・`DisclosureCaret` | 地震タブと同じものを読む（置き場所は動かさない。並行する見直しの取り込み先が壊れるため） |
| 縦画面の高さの配り方 | `src/utils/waveStackLayout.ts` | 止まる所の割合は `MAP_FLOOR_SHARE` |

# プライバシーポリシー

揺れ窓（以下「本アプリ」）が扱う情報について説明します。

最終改訂: 2026年11月7日

## まとめ

- **本アプリは、許可した場合だけ、使用状況データ（開いたタブ・使っている機能・設定・端末の種類など）を開発者の配信サーバーへ送信します。** 設定の窓でオフにできます（下記「1. 開発者が受け取る情報」）
- 設定でオンにした場合だけ、アプリを閉じていても通知を届けるため、通知の届け先と通知の設定を配信サーバーに登録します（下記「1. 開発者が受け取る情報」）
- 地震・津波などの情報は**開発者が運営する配信サーバー**から受け取ります。その際、配信サーバーには
  端末の IP アドレスなどが伝わります（下記「1. 開発者が受け取る情報」）
- 設定や表示の記録は、**利用者の端末の中**に保存されます。使用状況データとして送るものと、通知の届け先とともに登録する通知の設定を除き、端末の外へは出ません
- 本アプリは情報を受け取るために外部のサービスへ接続します。その際、通常のウェブ閲覧と同じく、
  接続先には端末の IP アドレスなどが伝わります

## 1. 開発者が受け取る情報

### 使用状況データ

まだお答えいただいていない端末では、開いたときにお尋ねし、許可した場合だけ、設定の窓の「使用状況データを送信する」がオンになります。
オンの間、次のものを開発者の配信サーバーへ送信します。

- **一意の識別子** — 初めて開いたときに端末で作るランダムな番号です。利用者の数（全体・機能ごと・設定ごと）を数えるために使います
- **技術データ** — アプリのバージョン・ホーム画面から開いたか・OS とブラウザの種類・画面の大きさの区分（スマートフォン・タブレット・パソコン）・表示言語
- **操作のデータ** — 開いたタブと、設定の窓を開いた回数、テスト時刻設定・テストボタン・共有カードを使った回数
- **設定のデータ** — 設定の窓や地震タブで選んでいる値（表示・通知・読み上げ・時報・地図・地震タブの絞り込みなど）。DMDATA.JP の API キー・接続先のアドレス・登録した地点は、入れているかどうかだけを送り、中身は送信しません。通知する地域は、選んだ都道府県の数だけを送ります

オンの間、配信サーバーは接続から次のものも数えます。

- 接続ごとの長さ
- おおまかな場所（国と都道府県。Cloudflare 社が IP アドレスから推定したものです。IP アドレスそのものは残しません）

使用状況データには、名前・メールアドレス・IP アドレスと、登録した地点・入力したキーの中身を含めません。

- **保存する期間** — 1 件ずつの記録は 3 か月で消えます。月ごとにまとめた数（人数・割合など。1 人ずつは辿れないもの）は期限を決めずに残します
- **使いみち** — 利用者の数の把握と、本アプリの改善だけに使います。第三者へは渡しません（記録は Cloudflare 社のサービス上に保存します）
- **オフにすると** — 送信が止まり、端末の識別子も消えます。オフにしたあとに改めてオンにすると、別の識別子になります。すでに送った分は、上記の期間で消えます

アクセス解析サービス（Google Analytics 等）やエラー収集サービスは組み込んでいません。集計は開発者の配信サーバーで行います。

### 通知の届け先

設定の窓の「プッシュ通知」をオンにすると、アプリを閉じているときにも通知を届けるため、次のものを開発者の配信サーバーに登録します。

- **通知の届け先と鍵** — ブラウザが作る、この端末へ通知を届けるための宛先と、通知の中身を暗号化する鍵です
- **通知の設定** — 通知する情報の種類・最低震度・選んだ都道府県

登録した内容と一緒に、IP アドレスや使用状況データの識別子を保存することはありません。

- **使いみち** — 通知を送るために使います。第三者へは渡しません
- **通知の中身** — 暗号化したうえで、ブラウザの通知の配送サービス（ブラウザによって Google・Microsoft・Mozilla・Apple のいずれか）を通って届きます
- **オフにすると** — 登録を消します。そのとき通信できなかった場合や、アプリを削除した場合は、通知が届かなくなった時点で配信サーバーが消します

### 配信サーバー

本アプリは、地震・津波などの情報を、開発者が運営する配信サーバー（Cloudflare 社のサービス上で動いています）から
受け取ります。接続するとき、通常のウェブ閲覧と同じく、配信サーバーには端末の IP アドレス・ブラウザの種類などが伝わります。

- 配信サーバーは、接続や取得の 1 回ごとに、どこから何を取ったかの記録を残しません。許可を問わず、札の発行・接続の受け付け・同時に接続している数を、誰のものか分からない数として記録し、3 か月で消えます
- 端末の IP アドレスは、同じ相手からの接続や取得の回数に上限を設けるためだけに使い、保存しません
- 残るのは、配信サーバー自身の動作の記録（配信元との接続の状態など）と、Cloudflare 社が集計した数（届いた要求の数・成否など）だけです（許可した場合は、上記の使用状況データも残ります）

### アプリ本体の配信

本アプリのファイルは Cloudflare 社のサービス（Cloudflare Pages）から配信されているため、Cloudflare 社のサーバーには
アクセスの記録が残る可能性があります。以前のアドレス（`ramilen-l-emuruk.github.io`）は GitHub Pages に置いた
案内のページで、GitHub 社のサーバーにアクセスの記録が残る可能性があります。

## 2. 端末の中に保存されるもの

次の情報が、ブラウザの保存領域に保存されます。
**API キー・一意の識別子、使用状況データとして送る設定のデータ、プッシュ通知をオンにしたときの通知の設定を除き、いずれも端末の外へ出ることはありません**（API キーの送り先は下記「4. 入力したキーの扱い」、一意の識別子と設定のデータは上記「使用状況データ」、通知の設定は上記「通知の届け先」）。

### 設定

表示・通知・読み上げなどの設定一式。次のものを含みます。

- **登録した地点の緯度・経度**（「ホーム地点」を設定した場合）
- **DMDATA.JP の API キー**（入力した場合）

### 表示の記録

- 行動チェックリストを畳んだ記録
- 閉じた帯の記録（南海トラフ地震臨時情報・関連解説情報・後発地震注意情報・地震回数・お知らせ）
- 揺れ検知エンジンが観測点ごとに学習した値
- 揺れていないときの観測点ごとのゆらぎを、受け取ったリアルタイム震度から数え直した値（揺れ検知の確かさを、その端末で受け取った値に合わせるため）
- 自作地震計の観測点ごとに、最後に測れた静かさ（波形グラフの縦の目盛りを決めるため）
- 最後に開いたアプリのバージョン（更新したあとに、何が変わったかを知らせるため）
- 使用状況データの一意の識別子（「使用状況データを送信する」をオフにすると消えます）
- 使用状況データとして最後に送った設定の控え（同じ日に同じ設定を何度も送らないため。「使用状況データを送信する」をオフにすると消えます）
- 使用状況データの送信を尋ねる窓に答えた記録（二度と尋ねないため）
- 新しいバージョンの読み込みや適用がうまくいかず読み直したこと（読み直しを繰り返さないため。タブを閉じると消えます）

### 受け取った情報の控え

同じ情報を何度も取りに行かないための控えです。一定の件数・容量・期間を超えたものから
自動的に消えます。

- 受け取った電文の原文
- 過去の電文のアーカイブ
- 地震活動の集計
- 揺れ検知の診断記録
- 取り込んだ強震波形データ（設定の窓から読み込んだ場合）
- 緊急地震速報の発生時刻（地震カードの波形に P 波・S 波の線を引くため）
- 地震カードに出す、気象庁の広帯域地震計の波形（合計 50 MB を超えたら、発生の古い地震の分から消えます）

### アプリ本体

オフラインでも動くよう、アプリのファイルがブラウザのキャッシュに保存されます。
地図の境界・観測点の位置・読み上げに使う読み方の辞書も、一度読み込んだものがブラウザのキャッシュに保存されます。
海底地形の地図画像も、表示したもの（録画モードでは先に読み込んだもの）がブラウザのキャッシュに保存されます（全部で約 60 MB まで）。

## 3. 位置情報の扱い

設定の窓で「現在地を取得」を押したときだけ、ブラウザの位置情報機能を使います。
その際ブラウザが許可を求めます。

- 取得した緯度・経度は**設定として端末内に保存されるだけ**で、どこへも送信されません
- 使いみちは、揺れの強さを判定する範囲の中心と、主要動の到達予想を出す地点の決定です
- 位置情報を使わなくても、本アプリのほかの機能はすべて利用できます
- 設定の窓から削除できます

## 4. 入力したキーの扱い

**DMDATA.JP の API キー**（入力した方のみ）は**暗号化されずに端末内へ保存されます**。共有の端末では利用にご注意ください。

緊急地震速報の予報を受けるため、DMDATA.JP へ接続するときに使います。上記の用途のほかには使われず、それ以外の第三者へ送信されることはありません。
不要になったら設定の窓で消してください。

なお、設定の書き出し機能で作られるファイルには、既定ではキーは含まれません。
書き出すときに「鍵も含める」を選んだ場合だけ含まれます。その場合は、ファイルを人に渡したり、公開の場所に置いたりしないでください。

## 5. 接続する外部サービス

本アプリは次のサービスへ接続します。通常のウェブ閲覧と同じく、接続先には端末の
IP アドレス・ブラウザの種類などが伝わります。各サービスの扱いは、それぞれの
プライバシーポリシーをご確認ください。

| 接続先 | 目的 | いつ |
|---|---|---|
| 配信サーバー（開発者が運営。Cloudflare 社のサービス上。`relay.yuremado.com`・`data.yuremado.com`） | 地震・津波・緊急地震速報などの受信、過去の情報の取得 | 利用中つねに |
| [DMDATA.JP](https://dmdata.jp/) | 緊急地震速報の予報の受信 | API キーを設定したとき |
| [Yahoo!天気・災害](https://weather.yahoo.co.jp/weather/) | リアルタイム震度と緊急地震速報の受信。下記の Akamai で時計を補正できないときは、その代わりにも使います | 利用中つねに（毎秒） |
| Akamai（`time.akamai.com`） | 端末の時計のずれを補正 | 利用中つねに（数十秒ごと） |
| Esri（`tiles.arcgis.com`） | 海底地形の地図画像 | 地図に海底地形を表示しているとき。**録画モードを有効にしている間は、表示の設定にかかわらず地図画像を先に読み込みます** |
| [EarthScope](https://www.earthscope.org/)（`rtserve.earthscope.org`） | 気象庁の広帯域地震計の波形の受信 | 揺れを検知したときと、緊急地震速報の発表中。設定の窓のテストボタンで緊急地震速報のテストを流したときも、近くの実在の観測点へ実際に接続します。設定「公開観測点に常時接続」を有効にしている間は利用中つねに。テスト時刻設定で再生している間は接続しません。設定「公開観測点の波形を表示」を無効にしている間は接続しません |
| [EarthScope](https://www.earthscope.org/)（`service.earthscope.org`） | 気象庁の広帯域地震計の観測点の情報（位置・感度など）の確認 | 開いてから観測点の波形が初めて必要になったとき（開いている間に 1 回） |
| [EarthScope](https://www.earthscope.org/)（`service.earthscope.org`） | 気象庁の広帯域地震計の過去の波形の受信（地震カードと、テスト時刻設定で再生している間の地図の下端の波形に出すため） | 地震カード: 起動時と、震度を観測した地震の情報が届いたとき（新しい地震から 100 件まで。それより古い地震は、そのカードを開いたとき）。控えに残っている地震は取りに行きません。テスト時刻設定で再生している間も、再生している時刻の分を取ります。地図の下端の波形: テスト時刻設定で再生している間、揺れを検知したときと緊急地震速報の発表中に、再生している時刻の分を取ります（設定「公開観測点に常時接続」を有効にしている間は再生中つねに）。設定「公開観測点の波形を表示」を無効にしている間は、どちらも取りに行きません |
| Cloudflare Pages（`yuremado.com`） | アプリ本体と地図データの配信 | 起動時 |
| ブラウザの通知の配送サービス（Google・Microsoft・Mozilla・Apple のいずれか。ブラウザが決めます） | プッシュ通知の受け取り | 設定「プッシュ通知」をオンにしている間 |
| VOICEVOX | 読み上げの音声合成 | 読み上げを有効にしたとき。**接続先は利用者が指定します**（初期値はご自身の端末内） |
| 自作地震計のホスト | ご自身で設置した地震計の観測データの受信 | 「自作地震計と接続」を有効にし、URL を入力したとき。**接続先は利用者が指定します**（初期値は空欄で、既定では接続しません） |

いずれの接続でも、本アプリが利用者を識別する情報を送ることはありません（上記「4. 入力したキーの扱い」の API キーと、配信サーバーへ送る一意の識別子と通知の届け先（上記「1. 開発者が受け取る情報」）を除きます）。

## 6. Cookie

本アプリは Cookie を使用していません。

## 7. 保存された情報の削除

ブラウザの設定から、本アプリのサイトデータを削除すると、上記のすべてが消えます。

- **Chrome / Edge**: 設定 → プライバシーとセキュリティ → サイトの設定 → 保存されているデータ
- **Safari**: 設定 → Safari → 詳細 → Web サイトデータ
- **Firefox**: 設定 → プライバシーとセキュリティ → Cookie とサイトデータ

設定の窓の「ホーム地点」「接続」からは、個別に削除できます。

## 8. お子様の利用について

本アプリは年齢を問わず利用できます。名前など利用者を特定する情報を集めないため、年齢確認は行いません。

## 9. このポリシーの変更

内容を変更することがあります。変更後の内容は、本アプリに掲載した時点から適用されます。

# `isDmdss` の割り当て表

標準版と DMDSS 版を 1 つにまとめた（[`relay-server-design.md`](relay-server-design.md) §0・§7.2）ので、版を分けていた `isDmdss`（`src/utils/env.ts`）は無くなった。
この表は、まとめる前の 5.75.1 の時点の参照 1 行ずつを、まとめた後に何で判定するかへ割り当てた記録。割り当ての根拠は §0 の決めごとで、未決だった 9 か所は 2026-10-31 に §0 で埋めた（下の「未決だった行と、埋めた決めごと」）。段 3b でこの表どおりに差し替え、`isDmdss` と `src/utils/env.ts` を消した。表の「行」と「まとめる前」の列は 5.75.1 の時点のもの。

- **数えた時点**: `main` の 5.75.1（`d7c2b6dc`）。行番号はこの時点のもの
- **数え方**: `grep -rn isDmdss src`（`*.ts`・`*.tsx`）から `*.test.*`・`*.probe.*` を除いた 129 行。コメントの中の言及も含む。設計書 §7.2 の「105 行」は 2026-10-14 時点の数

## 割り当ての種類

| 種類 | 意味 |
|---|---|
| **中継** | DMDATA の電文（XML）が届いているか。まとめた後は中継に繋がっていれば鍵が無くても成り立つ。DMDSS 版でしか出していなかった表示・設定・テストボタンの多くはここへ入る |
| **鍵** | 自分の鍵が入っているか。予報（`eew.forecast`）と、中継が配らない DMDATA の加工データ（`/v2/gd/*`）を自分で取る経路 |
| **消える** | 版が 1 つになると分ける意味が無くなるもの（タイトル・保存先の鍵・変更履歴の版の区別・P2PQuake の経路） |
| **未決** | 設計書 §12 の決めごとで行き先が変わる。決まるまで割り当てない（2026-10-31 の時点で残りは無い） |

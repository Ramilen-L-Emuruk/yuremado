# VOICEVOX で読み上げる

揺れ窓は、地震・緊急地震速報・津波情報を [VOICEVOX](https://voicevox.hiroshiba.jp/)（無料の音声合成ソフト）の声で読み上げられます。
VOICEVOX は揺れ窓に含まれていないので、自分のパソコンで起動しておく必要があります。
声ごとの利用規約は VOICEVOX の公式サイトにあるので、使う前に確かめてください。
VOICEVOX を用意しなくても、端末の声（設定の「システムの読み上げ」）で読み上げられます。VOICEVOX を使うと、話者を選べ、地名の読みとアクセントの調整も効きます。

ここでは、揺れ窓を開くパソコンと同じパソコン（Windows）で VOICEVOX を動かす手順を説明します。
別のパソコンで動かしている VOICEVOX に繋ぐ方法は、この手順には含みません。

## 1. VOICEVOX を用意する

[VOICEVOX の公式サイト](https://voicevox.hiroshiba.jp/)から VOICEVOX を入手してインストールします。

VOICEVOX は、画面のついたアプリ（エディタ。`VOICEVOX.exe`）と、裏で声を作る部分（エンジン。`run.exe`）でできています。
揺れ窓が使うのはエンジンです。設定の窓には「要：VOICEVOXアプリ起動」とありますが、この手順ではエディタではなくエンジンを起動します。

エンジンは、`VOICEVOX.exe` と同じフォルダにある `vv-engine` フォルダの中の `run.exe` です。
見つからないときは、VOICEVOX をインストールしたフォルダの中で `run.exe` を探してください。

## 2. 揺れ窓からの接続を許可して起動する

エンジンは、そのままでは揺れ窓のようなウェブサイトからの呼び出しを受け付けません。
揺れ窓（`https://yuremado.com`）から呼び出せるように、起動するときに `--allow_origin` で許可します。

1. エクスプローラーで `vv-engine` フォルダを開きます
2. アドレス欄に `cmd` と入力して Enter を押すと、そのフォルダでコマンドプロンプトが開きます
3. 次のように入力して Enter を押します

```
run.exe --allow_origin https://yuremado.com --port 50021
```

- 起動している間だけ使えます。コマンドプロンプトの画面を閉じると止まります
- エディタも同じ番号（50021）でエンジンを動かします。エディタを開いたままで起動に失敗したときは、エディタを閉じてからもう一度起動してください

## 3. 揺れ窓で有効にする

1. 揺れ窓のアイコンの並びから「設定」を押し、設定の窓を開きます
2. 分類の一覧から「音と読み上げ」を選びます
3. 「読み上げ」をオンにし、「読み上げの声」を「VOICEVOX」にします（下に「VOICEVOX」の見出しが出ます）
4. 「VOICEVOX」の見出しの下の「VOICEVOX URL」が `http://localhost:50021` になっていることを確かめます（変えていなければ、この値が入っています）
5. 「接続状態」が「起動中」になれば繋がっています
6. 「話者」で声を選び、「▶ 試聴」で声が出ることを確かめます

## 4. うまくいかないとき

「接続状態」が「起動していません」のままなら、次を確かめてください。

- エンジンを起動したコマンドプロンプトの画面が開いたままで、エラーが出て止まっていないか（エディタを開いたままだと、同じ番号を取り合って起動に失敗することがあります）
- 起動するときに `--allow_origin https://yuremado.com` を付けたか（付けずに起動したエンジンは、動いていても揺れ窓からの呼び出しを受け付けません）
- 「VOICEVOX URL」の番号が、起動したときの `--port` の番号と同じか

「接続状態」が「URLが無効」なら、「VOICEVOX URL」を `http://` または `https://` で始まる形（`http://localhost:50021`）で入れ直してください。

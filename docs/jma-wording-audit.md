# 利用者向けの文言と気象庁の語の突き合わせ

**読み手**: 画面・読み上げ・通知・共有カードの文言を直す人。
**何の資料か**: 地震・津波・緊急地震速報の値に付けている語のうち、気象庁の資料に公式の語があるのに、アプリが別の言い方をしている箇所の台帳。直したら行は消さず、「候補」の欄に直した版と日付を書き添える。

文言を変えるときの手順は [`ui-wording-procedure.md`](ui-wording-procedure.md)、わざと外している語の表は [`spec/quake-spec.md`](spec/quake-spec.md) §8「気象庁の表現からわざと外している語」。**「候補」の欄はどれも未決。** 直す前に、文面をユーザーへ諮る。

## 調べた範囲と出典

- **基準**: コミット `630a7471`（版 5.59.1）の `src` 配下。`npm run list-ui-strings -- src` で取った文字列（印が `text` のもの 2847 件）をすべて見た。`log`・`error` の印の文字列は、画面に出るものだけを見た。JSON の利用者向けの欄は別に見た（E24）
- **行番号は基準のコミットでのもの。** ずれていたら、「文言」の欄の文字列で探す
- **見ていないもの**: 強震モニタ・自作地震計・揺れ検知・行動チェックリストなど、気象庁の電文に由来しない値。数字の全角と半角（§8 で決着済み）。コミット `d1fad5355`（2026-09-30）で揃えた情報名
- **公式の語の出典**（表の略記）
  - `eq:行` … 気象庁「地震火山関連 XML 電文 解説資料」。[技術資料のページ](https://xml.kishou.go.jp/tec_material.html)の `jmaxml_20261009_Manual(pdf).zip` に入っている `地震火山関連_解説資料.pdf` を `pdftotext -enc UTF-8` で文字にしたときの行番号。**資料の版が変わると行番号は使えない**ので、要素名【公式名】も併せて書く
  - コード表 … 同じページの `jmaxml_20261019_Code.zip` の `地震火山関連コード表.xlsx`（固定付加文・緊急地震速報の警報コード・津波の区分）
  - web … 気象庁「[緊急地震速報の内容](https://www.jma.go.jp/jma/kishou/know/jishin/eew/shikumi/shousai.html)」
- **確かめていないもの**: 気象庁の地震情報のページでの時刻の表記、P2PQuake 側の語、推計震度分布図（二進の電文）の名称、固定付加文 0213・0214・0216 が実際の電文でどれだけ届いているか

### 表の読み方

- **場所**は、`src/` からの相対パスと行番号。括弧の中は届き方（画面・地図の吹き出し・ホバー・凡例・通知・ウィンドウタイトル・共有カード・読み上げ・設定タブ）
- **種類**は次の 4 つ
  - **言い換え**: 公式の語があるのに、別の語を使っている
  - **短縮**: 公式の語を縮めて、意味が落ちている
  - **別の値に公式名**: ある値に、別の値の公式の名前を付けている
  - **公式の名なし**: 公式の名前が無い値に、公式らしい名前を付けている
- **確かさ**は、食い違いだと言える確かさ。「低」は、公式の語が一般語でもある・出典が弱い・食い違いと言えるかに判断が要るもの
- **候補**は直す文面の候補。決まっていない

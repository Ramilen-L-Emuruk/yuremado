# `isDmdss` の割り当て表

標準版と DMDSS 版を 1 つにまとめる（[`relay-server-design.md`](relay-server-design.md) §0・§7.2）と、版を分けている `isDmdss`（[`src/utils/env.ts`](../src/utils/env.ts)）は無くなる。
この表は、いまの参照 1 行ずつを、まとめた後に何で判定するかへ割り当てたもの。**割り当ては §0 の決めごとから導いた案で、承認済みではない。** **コードはまだ変えていない。** 実際に差し替えるのは段 3b 以降。

- **数えた時点**: `main` の 5.75.1（`d7c2b6dc`）。行番号はこの時点のもの
- **数え方**: `grep -rn isDmdss src`（`*.ts`・`*.tsx`）から `*.test.*`・`*.probe.*` を除いた 129 行。コメントの中の言及も含む。設計書 §7.2 の「105 行」は 2026-10-14 時点の数

## 割り当ての種類

| 種類 | 意味 |
|---|---|
| **中継** | DMDATA の電文（XML）が届いているか。まとめた後は中継に繋がっていれば鍵が無くても成り立つ。DMDSS 版でしか出していなかった表示・設定・テストボタンの多くはここへ入る |
| **鍵** | 自分の鍵が入っているか。予報（`eew.forecast`）と、中継が配らない DMDATA の加工データ（`/v2/gd/*`）を自分で取る経路 |
| **消える** | 版が 1 つになると分ける意味が無くなるもの（タイトル・保存先の鍵・変更履歴の版の区別・P2PQuake の経路） |
| **未決** | 設計書 §12 の決めごとで行き先が変わる。決まるまで割り当てない |

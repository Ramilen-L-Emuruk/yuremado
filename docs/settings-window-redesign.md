# 設定の窓の見直し

設定の窓（歯車で開く窓。分類の一覧と、その中身）の見た目を、地震タブの作り直し（[`quake-tab-redesign.md`](quake-tab-redesign.md)）に合わせて見直すための資料。
読み手は、この見直しに関わる開発者。仕様としての正は [`spec/settings-pwa-spec.md`](spec/settings-pwa-spec.md) §2 で、ここには決めた経緯と原文を残す。
